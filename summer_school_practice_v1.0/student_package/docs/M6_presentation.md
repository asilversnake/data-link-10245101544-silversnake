# 数据链处理链综合展示

## 第1页：完整流程概览

```
OpenSky原始数据 ──▶ 发送方解析 ──▶ 41字节帧编码 ──▶ 模拟传输
                                                               │
一致性检查 ◀── 语义映射 ◀── 当前态势 ◀── 航迹关联 ◀── 接收解码 ◀──┘
```

- **M2**: 9条OpenSky记录 → 8帧编码 → 8帧解码 → 1条编码错误（heading越界）
- **M3**: 9帧多时刻消息 → 3条航迹 → 3目标当前态势 + SQLite持久化
- **M4**: OpenSky + TeachingLink → 6条统一模型消息（人工核验映射）
- **M5**: 10条测试记录 → 10条告警（3 HIGH, 7 MEDIUM） → 9条质量态势

## 第2页：编解码与量化精度

### TeachingLink 41字节帧结构
| 偏移 | 字段 | 类型 | 规则 |
|------|------|------|------|
| 0-1 | magic | uint16 | 0x4453 |
| 2 | version | uint8 | 1 |
| 3 | message_type | uint8 | 1 |
| 4-5 | message_length | uint16 | 41 |
| 6-7 | message_seq | uint16 | 发送序号 |
| 8-11 | timestamp | uint32 | Unix秒 |
| 12-14 | target_id | uint24 | 6位hex |
| 15-22 | callsign | ASCII×8 | 补0 |
| 23-28 | lat/lon | 22bit×2 | 量化编码 |
| 29-36 | alt/spd/hdg/vr | uint16×4 | 偏置+分辨率 |
| 37-38 | flags | uint8×2 | 状态+有效性 |
| 39-40 | checksum | uint16 | 前39字节和模65536 |

### 往返精度
- 经纬度: ~0.0001度误差（22位量化）
- 高度: 1米分辨率
- 速度: 0.1米/秒分辨率
- 航向: 0.01度分辨率
- 全部通过容差检查（<=1个量化单位）

## 第5页：工程实践总结

### 关键经验
1. **字节序至关重要**: 大端字节序编码错误会导致所有数值错误
2. **空值≠零值**: None（字段缺失）与0（有效物理零值）语义完全不同
3. **保留位必须检查**: 编码时清零，接收时验证
4. **量化不可逆**: 定点编码后只能恢复到最近量化值
5. **人工核验不可跳过**: LLM候选需要逐项核对

### 改进方向
- 增加更多边界值测试（极值、NaN、溢出）
- 支持多源数据融合（多个TeachingLink接收端）
- 增加实时数据接口
- 实现更复杂的航迹预测算法
