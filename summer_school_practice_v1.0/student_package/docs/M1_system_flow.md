## 各组件说明

### 1. 发送方 (M2 Parse)
- **输入**: raw_states.json (OpenSky状态向量数组)
- **输出**: 发送方内部结构化记录
- **关键处理**: 字段解析、必需字段验证、可空字段处理、时间回退、高度来源选择

### 2. 编码器 (M2 Encode)
- **输入**: 发送方内部记录
- **输出**: 41字节TeachingLink二进制帧
- **关键处理**: Q函数量化、比例因子/偏置、22位经纬度编码、标志位设置、校验和计算

### 3. 模拟传输
- **输入**: 编码后的41字节帧
- **输出**: encoded_messages.bin
- **关键处理**: 逐帧追加写入，无网络传输

### 4. 接收方 (M2 Decode)
- **输入**: 41字节二进制帧
- **输出**: 解码结构化记录 + validation_log
- **关键处理**: 帧头验证、checksum校验、保留位检查、标志一致性检查、物理值恢复

### 5. 存储 (M3)
- **输入**: 解码记录
- **输出**: CSV文件、SQLite数据库(选做)
- **关键处理**: None→NULL映射、UTF-8 with BOM编码

### 6. 航迹关联 (M3)
- **输入**: decoded_multitime.csv
- **输出**: track_table.csv, current_situation.csv
- **关键处理**: target_id分组、timestamp排序、track_sequence_no编号、最新记录提取

### 7. 语义映射 (M4)
- **输入**: OpenSky态势 + TeachingLink态势
- **输出**: unified_situation.ndjson
- **关键处理**: LLM候选生成、人工核验、定点数解码、空值策略统一

### 8. 一致性检查 (M5)
- **输入**: 混合态势数据 + 固定规则
- **输出**: alert_log.csv, quality_situation.csv
- **关键处理**: 四类必做规则执行、告警等级判定、display_status合成
